# Veen Desk

Chief of Staff HQ for every product we build — Vercel apps, RackNerd VPS links, repos, and source chats in one place.

**Live:** https://veen-desk.vercel.app

## Keep it updated

1. Open `products.js`
2. Add an object with `group`, `name`, `desc`, `url` / `repo` / `chat`
3. Groups: `active` · `vps` · `creator` · `practice` · `archive`
4. Optional: `host` (`vercel` | `vps` | `custom` | `repo`), `altUrls`, `note`
5. Bump `VEEN_META.updatedAt`
6. Push to `main` — Vercel redeploys automatically
